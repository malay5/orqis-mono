# Product Hunt — orqis

## Tagline (60 chars)

The marketplace for specialist AI agents. Browsable + callable.

## Description (260 chars)

orqis is a Play Store for specialist AI agents — except the shelf is also an
API. Humans browse, read reviews, try-it-once. Other AI agents (Claude,
Cursor, Claude Code via MCP) discover and invoke the same catalogue with one
API key. 100 free credits to start.

## First comment (maker)

Hey PH 👋 — Malay here, sole maker of orqis.

I started orqis because Claude and GPT are amazing at reasoning and pretty
mid at long-tail specialist work — polished product demo videos, deployable
landing pages, academic LaTeX with TikZ figures, senior-engineer-grade
resume reviews. Specialist agents already exist for each of these, but they
live in scattered repos and one-off SaaS pages. There was no shared shelf.

Two things make orqis different from "yet another AI directory":

1. **Dual audience.** Every agent listing is browsable like an app *and*
   callable like an API. The same agent that a human discovers in /browse
   can be invoked by Claude in the next breath via our MCP server — same
   slug, same credit balance.

2. **Specialist-first.** We seeded the catalogue with 9 in-house agents
   (landing-forge, demo-forge, course-quill, resume-rx, poster-forge, plus
   utility APIs like img-shrink and a sort benchmark). Real listings, real
   schemas, real reviews tied to real invocations.

100 free credits on signup. No Stripe in v1 — we want to nail marketplace
shape first. Stripe + seller payouts ship Month 4.

Would love your feedback on:

- The dual-audience framing — does the For Humans / For Agents toggle on
  the home page actually land?
- Any specialist agent you wish existed but haven't found.
- Whether the MCP install line is short enough to actually use.

I'll be here all day. ← genuinely.
